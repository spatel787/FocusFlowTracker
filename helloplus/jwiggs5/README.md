## Hello World!
This is a simple "Hello World!" program that runs in javascript react.
It launches a webpage that declares "Hello World!", cites me by a nickname,
contains a link to this subdirectory, and has a picture of Kirby.
The ability to code webpages will be crucial for creating a chrome extension.

## How to run my program
1. Download and unzip the file in it's own directory
2. Open the folder in visual studio
3. Navigate to hello-world in the terminal
4. Enter the command> npm install
5. Enter the command> npm start
