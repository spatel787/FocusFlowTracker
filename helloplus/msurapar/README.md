# Focus Timer

This project is a simple React app built with Vite that demonstrates a 25-minute countdown timer as part of the Focus Flow Tracker Chrome Extension concept. The timer starts at 25 minutes, counts down in real time, and displays the remaining time in mm:ss format. It is styled to appear in the center of the page and stops automatically at 00:00. To run the project, first install dependencies with npm install, then start the development server with npm run dev, and open the URL provided in the terminal (usually http://localhost:5173). The main logic is in App.jsx, styling in index.css, and rendering setup in main.jsx. This timer can be extended with features like start/pause/reset buttons and integrated with Chrome Extension scripts to help users track focus and manage digital habits.
